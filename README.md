# 🚀 Meu Projeto React + Node

Aplicação Full Stack desenvolvida com React, Vite, Node.js e Express.

## 📋 Sobre o Projeto

Este projeto foi criado para demonstrar a integração entre um frontend React e uma API Node.js utilizando Express.

A aplicação consome dados da API e exibe as informações em tempo real na interface do usuário.

## 🛠 Tecnologias Utilizadas

### Frontend
- React
- Vite
- JavaScript
- Fetch API

### Backend
- Node.js
- Express
- CORS
- Dotenv

### DevOps
- Git
- GitHub
- GitHub Actions (CI)

## ⚙️ Instalação

### Clonar o repositório

```bash
git clone https://github.com/maristelagatinhapreta-jpg/meu-projeto-react-node.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```

## 🌐 Endereços Locais

Frontend:

```text
http://localhost:5173
```

Backend:


## ✅ Integração Contínua

Este projeto utiliza GitHub Actions para:

- Instalar dependências
- Validar o frontend React
- Executar o build da aplicação
- Verificar o backend Node.js
